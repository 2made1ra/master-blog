# Многоуровневый инференс детекции объектов

Статичная страница-презентация темы магистерской работы (УрФУ, прикладной анализ данных): управление вычислениями при детекции объектов в видеопотоке по сигналам неопределённости при сдвиге домена.

## Структура

```
index.html      разметка и контент
css/styles.css  стили, темы (светлая/тёмная), адаптивность
js/main.js      анимации: сцена-гейт, графики, появление блоков при скролле, навигация
```

Сборки и зависимостей нет. Единственный внешний ресурс — шрифты Google Fonts (Inter, Martian Mono).

## Локальный запуск

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.

## Деплой

Vercel: Framework Preset — Other, без Build Command и Output Directory.
